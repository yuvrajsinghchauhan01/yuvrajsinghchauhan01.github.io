TubeScope

Privacy policy

Last updated: November 15, 2026

TubeScope is a personal tool that runs only on its owner's own computer. It is not offered to the public. This policy explains how it handles data from Google and YouTube.

Data TubeScope accesses

When the owner signs in with Google, TubeScope requests read-only access to:

  • YouTube Data API (youtube.readonly): to identify the signed-in channel and read public video details.
  • YouTube Analytics API (yt-analytics.readonly): to read the channel's own analytics, such as views, watch time, audience retention, subscribers gained and traffic sources.

TubeScope cannot upload, edit, delete or post anything.

How data is used

Data is used only to show the channel owner their own statistics and research results inside TubeScope on their own computer.

Storage

Sign-in tokens and cached results are stored in a local database file on the owner's computer. Nothing is sent to any server operated by TubeScope; there is none. Data goes directly between the owner's computer and Google's APIs.

Sharing

TubeScope does not sell, share or transfer any data to third parties, and does not use it for advertising.

Removing access and data

Pressing Disconnect in TubeScope revokes its access token and deletes the stored tokens and cached analytics for that channel. Access can also be removed at any time at myaccount.google.com/permissions. Deleting TubeScope's data folder removes everything it stored.

Google and YouTube

TubeScope uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of your data is covered by the Google Privacy Policy. TubeScope's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact
